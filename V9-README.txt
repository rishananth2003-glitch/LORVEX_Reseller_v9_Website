LORVEX RESELLER V9

V9 is an HTTPS-first Firebase Hosting build.

- Responsive for phone, tablet, laptop and desktop.
- Firebase Authentication.
- Local/file preview no longer tries to authenticate.
- content:// and file:// automatically redirect to:
  https://lorvex-reseller.web.app
- Firebase Hosting configuration included.

Deploy with:
firebase deploy --only hosting
